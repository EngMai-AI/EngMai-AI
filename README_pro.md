## 🔭 Featured projects

### 🦷 [Oral Diseases Image Classification](https://github.com/EngMai-AI/oral-diseases-classifier)
Cleaned the dataset (13,862 → 3,322 images, 5 classes), then benchmarked a custom CNN against three pretrained models. Deployed with Gradio.

| Model | Accuracy | Macro-F1 | Params |
|---|---|---|---|
| **MobileNetV2** | **95.6%** | **0.932** | 2.59M |
| DenseNet121 | 94.4% | 0.920 | 7.30M |
| EfficientNetB0 | 94.0% | 0.896 | 4.38M |
| Custom CNN | 68.1% | 0.639 | 1.24M |

`TensorFlow/Keras` `Transfer Learning` `Gradio`

### 🎗️ [Breast Cancer Risk Stratification with Explainable AI](https://github.com/EngMai-AI/breast-cancer-ai-risk-stratification)
- Deep learning classifier with ROC-AUC evaluation and a tunable decision threshold
- SHAP explanations for each prediction, shown in a Streamlit app

`TensorFlow` `SHAP` `Streamlit`

### ✋ [Virtual Whiteboard](https://github.com/EngMai-AI/virtual-whiteboard)
- Index fingertip as a pen, using MediaPipe Hands (21 landmarks)
- Gesture recognizer for draw, select, erase, and clear, plus undo/redo and shape correction

`Python` `MediaPipe` `OpenCV`

### 🛡️ [IoT Intrusion Detection System](https://github.com/EngMai-AI/Iot-intrusion-detection)
